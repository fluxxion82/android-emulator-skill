01 / WHY

Why it matters.

Principles applied to every script.

A

Token-efficient by default

Default output is a few lines. Drill into errors, warnings, or full logs only when you need them with --verbose and --json.

B

Semantic UI navigation

Find elements by meaning — text, type, or resource ID — not pixel coordinates. Built on the uiautomator hierarchy, so tests survive UI redesigns.

C

Emulators and real devices

Everything runs through adb, so the same scripts drive emulators and physical devices. Multiple emulators are supported with batch operations and --serial targeting.

D

Production-ready

Class-based scripts, modern type hints, Black + Ruff CI, and a device-free pytest suite whose parsers read output recorded from real emulators. Auto device detection. Idempotent emulator lifecycle (create / boot / shutdown / erase / delete).

02 / CATALOG

33 scripts. 8 categories.

Every script supports --help and --json; those that drive a device auto-detect it unless you pass --serial.

/A

App Management

  • app_launcher.pyLaunch, terminate, install/uninstall APKs, deep links, list packages, app state. --launch · --terminate · --install · --uninstall · --open-url · --list · --state
/B

Device Lifecycle

  • emulator_boot.pyBoot AVDs with optional readiness wait and headless mode. --avd · --wait-ready · --timeout · --headless · --list-avds
  • emulator_shutdown.pyGracefully shut down emulators, with verification and batch support. --serial · --verify · --timeout · --all
  • emulator_create.pyCreate AVDs by device type and API level. --device · --api · --name · --abi · --variant · --list-devices · --list-images
  • emulator_delete.pyDelete AVDs permanently. --name · --list
  • emulator_erase.pyFactory-reset an AVD, wiping user data without deleting it. --name · --force · --list
  • snapshot.pySave, load and delete emulator snapshots; a failed load is a failure, not an adb emu exit 0. Emulator only. --list · --save · --load · --delete · --no-verify · --timeout
  • avd.pyOne entry point for the lifecycle: list, pick, create, start, stop, reset, delete, each routed to the script above that does it.
/C

Build & Development

  • build_and_test.pyGradle build, unit and instrumented tests with progressive disclosure; parses JUnit XML and Gradle/Kotlin/Java errors. --project · --module/-p · --variant · --clean · --test · --instrumented · --suite · --serial · --get-errors · --get-warnings · --get-log · --list-builds
  • log_monitor.pyReal-time logcat with package and severity filtering, dedup, and save-to-file. --app · --serial · --severity · --follow · --duration · --last · --output · --clear
  • crash_triage.pyParse the crash buffer (logcat -b crash) into crashes grouped by fault, naming the frame most useful for triage and why. --package · --clear · --fail-on-crash
  • logs.pyOne entry point for reading logs: tail, crashes, anr, routed to log_monitor.py, crash_triage.py and anr_watcher.py.
/D

Navigation & Interaction

  • screen_mapper.pyAnalyze the current screen and name every interactive control, by kind; listing is the default. --serial · --verbose · --hints
  • navigator.pyFind and interact with elements semantically (text, type, resource ID). --find-text · --find-type · --find-id · --tap · --enter-text · --list
  • gesture.pySwipes, scrolls, and long press, including edge swipes. --swipe · --from-edge · --duration · --long-press · --scroll
  • keyboard.pyType text, press hardware keys/buttons, clear input, hide the soft keyboard. --type · --delay · --key · --keys · --button · --clear · --hide-keyboard
/E

Testing & Analysis

  • accessibility_audit.pyWCAG checks: content descriptions, touch-target size, EditText hints, image accessibility. --serial · --output · --verbose
  • visual_diff.pyCompare two screenshots (positional: baseline, current) and write a per-pixel diff overlay. --output · --threshold
  • test_recorder.pyDocument a test run as a session: a screenshot and the UI hierarchy per step, then a report. --start · --step · --stop · --list · --get-details · --serial · --size · --app-name
  • app_state_capture.pyAll-in-one debugging snapshot: screenshot, UI hierarchy, logs, app info. --package · --output · --serial · --logs/--no-logs · --screenshot-size
/F

Permissions & Environment Control

  • privacy_manager.pyGrant/revoke runtime permissions (20+ types), with batch support. --grant · --revoke · --list · --package · --list-permissions
  • status_bar.pyDemo-mode status bar: battery, charging, WiFi/mobile signal, time. --battery · --charging · --wifi · --mobile · --time · --reset
  • push_notification.pyPost into the shade (as com.android.shell, not the app) and read back what is posted. --post · --tag · --text · --list · --expect-package · --grant-permission · --revoke-permission · --package
  • appearance.pyDark/light mode and font scale, best-effort locale. --theme · --text-size · --font-scale · --locale · --reset
  • location.pySimulate GPS via adb emu geo fix: fixed coords, city presets, GPX route replay (emulator only). --lat/--lng · --city · --gpx · --interval/--speed · --clear · --list-cities
  • sms.pyDeliver an inbound SMS to an emulator and read the inbox back to prove it arrived; extract a one-time code. Sending is emulator-only; --list and --otp work on any device. --send · --to · --body · --list · --otp
/G

Discovery & Device State

  • android_health_check.shVerify the environment (ANDROID_HOME, adb, emulator, avdmanager, sdkmanager, java, Python, Pillow) and list devices/AVDs.
  • device_list.pyList connected devices and defined AVDs with progressive disclosure. --get-details · --device-type/--name
  • emulator_selector.pySuggest the best AVD (running → recent → latest API → common models); list or boot one. --suggest · --list · --boot · --headless · --count
  • localization_audit.pyAudit res/values*/strings.xml for missing keys per locale and placeholder mismatches. --res · --source · --locale · --strict
/H

Inspection & Stability

  • container.pyInspect a debuggable app's sandbox via adb shell run-as: files, shared_prefs, SQLite schema, snapshot export. --package · --ls · --cat · --shared-prefs · --databases · --export · --get-cached
  • model_inspector.pyInspect Room annotations, exported-schema JSON, and live SQLite schema (Room == SQLite). --source · --schema · --show-versions · --raw · --package · --db
  • anr_watcher.pyRecord & summarise ANRs/jank from logcat with session-based progressive disclosure. Unix only (macOS, Linux). --start · --stop · --get-details · --list-sessions · --diff · --watch · --since · --terse

16 shared modules in common/ back the scripts above, among them common/device_utils.py (ADB command building & device detection), common/screenshot_utils.py (capture & resize), and common/cache_utils.py (progressive-disclosure cache). The Gradle build system lives in the gradle/ subpackage.

03 / INSTALL

Install as a Claude Code plugin.

Two commands. Restart Claude Code and the skill loads automatically.

claude-code 
/plugin marketplace add fluxxion82/android-emulator-skill
/plugin install android-emulator-skill@fluxxion82

Prerequisites: Android SDK with platform-tools & emulator · Python 3.12+ · ADB · Gradle (optional) · Pillow for screenshot resizing (optional).

04 / QUICK START

A typical flow.

Launch, map the screen, interact, and audit — all semantic, all token-light.

manual testing flow 
SCRIPTS=/path/to/skills/android-emulator-skill/scripts   # by path, not relative to the cwd
python3 "$SCRIPTS/app_launcher.py" --launch com.example.app
python3 "$SCRIPTS/screen_mapper.py"
python3 "$SCRIPTS/navigator.py" --find-text "Login" --tap
python3 "$SCRIPTS/navigator.py" --find-type EditText --enter-text "user@example.com"
python3 "$SCRIPTS/accessibility_audit.py"
